# Devent

This repo is an open source version of the luma events.

## Purpose

Devent is designed to help people organize events, specifically targeting engineers who need software to organize their tech events and contribute collaboratively.

## Audience

This project is intended for engineers and developers looking for an open source tool to manage and coordinate technology-related events.

## Current Status

This repository currently contains only the initial scaffolding and documentation. Implementation and usage instructions will be added as the project develops.
