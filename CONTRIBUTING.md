# Contributing to Devent

Thank you for your interest in contributing to Devent! As this project is in its early stages with only scaffolding and documentation, here are some ways you can help:

## How to Contribute

- **Discuss Ideas:** Use GitHub Issues to suggest features, report bugs, or discuss improvements.
- **Improve Documentation:** Submit pull requests to enhance or correct documentation.

## Pull Requests

When submitting a pull request:

- Describe the purpose and scope of your changes.
- Ensure your changes are focused and clear.
- Since there is no build or test suite yet, manual review will be used.

## Code and Implementation

Implementation and usage instructions will be added as the project progresses. Contributions to code will be welcomed once the initial development begins.

## Communication

Please use GitHub Issues and Pull Requests for all discussions to keep everything transparent and organized.

Thank you for helping build Devent!
